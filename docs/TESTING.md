## 실제 검증한 내용

- 추가 시 제목 자동 포커스, 인라인 제목·날짜·우선순위 수정, 메모 여러 줄 저장과 복구.
- 완료 체크 후 빨간 취소선의 실제 CSS 색상, 완료 숨김 및 다시 표시.
- 핀을 유지한 완료 처리와 새로고침 후 상태 복구.
- 삭제 확인 취소와 실제 삭제.
- 기한 삭제, 현지 자정 타이머로 D-1 → D-Day 변경, 윤년과 DST 날짜 산술.
- 모든 정렬 방식에서 핀 우선, 미설정 값 마지막, 같은 값의 안정적 순서.
- 마우스, 키보드, Chrome DevTools 터치 이벤트로 드래그, 순서 저장·재실행 후 유지.
- 순서 변경 함수에서 고정/일반 그룹 사이 이동 거절, 숨긴 완료 항목 보존.
- 브라우저 네트워크를 끊고 서비스 워커를 통한 페이지 재실행 및 오프라인 입력·저장·복구.
- JSON 다운로드, 잘못된 형식 거절, 복원 취소, 덮어쓰기 복원.
- IndexedDB 재연결, 복원 트랜잭션 실패 시 원래 데이터 유지.
- 기존 DB·백업 형식의 할 일을 미분류로 이전하고, 새 백업에 페이지와 할 일의 소속을 함께 보관. 버전 4에서는 기존 할 일을 보존하면서 Firebase 계정 메타데이터를 추가.
- 페이지 생성·이름 변경·삭제, 선택한 페이지에서 할 일 생성, 다른 페이지로 이동, 삭제 후 미분류 보존을 데스크톱·모바일에서 확인.
- 페이지 수정 모드에서 숫자 숨김·인라인 관리 버튼·여섯 점 손잡이를 확인하고, 마우스와 터치 드래그로 바꾼 순서가 재접속 후 유지되는지 확인.
- 빠른 연속 입력의 최종값 보존 및 저장 실패 후 재시도.

## 발견하여 수정한 문제

- 좁은 화면에서 텍스트가 숨겨진 정렬·설정 아이콘에 접근성 이름 추가.
- 키보드 드래그 손잡이에 activator ref 연결. 자동 스크롤을 즉시 처리하고 테스트에서 센서 초기화 시간을 반영.
- 테스트용 Chrome GPU 화면 캡처의 반복 타일 현상은 GPU 비활성화와 레이아웃 안정화 후 캡처로 해결.
- 개발 의존성의 보안 경고를 수정 버전으로 업데이트.

- 실제 iPhone/Android 기기의 설치 화면, 소프트 키보드, 실제 손가락 터치.
- 실제 새 배포를 통한 서비스 워커 업데이트 전환과 장시간 사용.
