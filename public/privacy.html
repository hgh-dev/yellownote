Yellow Note

개인정보처리방침

시행일: 2026년 10월 25일

Yellow Note는 할 일을 기록하는 웹 앱입니다. 이 문서는 앱이 기록과 Google Drive 데이터를 어떻게 다루는지 설명합니다. 문의: hussell.app@gmail.com

1. 처리하는 정보와 목적

앱은 사용자가 입력한 할 일 제목, 메모, 기한, 우선순위, 완료 여부와 정렬·표시 설정을 저장합니다. 기록을 구분하고 동기화하기 위한 고유 ID, 생성·수정·삭제 시각도 저장합니다. 이 정보는 노트 표시, 저장, 백업과 기기 간 동기화에만 사용합니다.

Google 계정 연결은 선택 사항입니다. 앱은 Google Drive의 앱 전용 저장 공간에 접근하기 위한 drive.appdata 권한을 요청합니다. Google 계정의 이메일 주소나 프로필을 별도로 조회하거나 저장하지 않습니다.

2. 저장 장소와 외부 서비스

  • 기본 기록과 설정은 사용 중인 브라우저의 IndexedDB에 저장됩니다. 저장이 끝나지 않은 변경사항은 복구를 위해 브라우저 localStorage에 임시 저장됩니다.
  • Google 계정을 연결하면 기록, 설정 및 삭제 기록이 사용자의 Google Drive 앱 전용 저장 공간에 동기화됩니다. 일반 Drive 파일 목록에는 표시되지 않습니다.
  • JSON 내보내기를 사용하면 백업 파일이 사용자의 기기에 다운로드됩니다. 파일 보관 위치와 공유 여부는 사용자가 관리합니다.
  • Yellow Note는 자체 서버에 노트 내용을 저장하지 않으며, 광고·분석 SDK를 사용하지 않습니다. 웹페이지 제공에는 GitHub Pages, 선택적인 로그인과 동기화에는 Google 서비스가 사용됩니다.

Google API를 통해 접근한 데이터는 요청한 동기화 기능을 제공하는 데만 사용하며 광고, 판매 또는 그 밖의 제3자 제공에 사용하지 않습니다.

3. 보관 기간과 삭제

브라우저의 기록은 사용자가 할 일을 삭제하거나 해당 사이트의 브라우저 데이터를 지울 때까지 남습니다. 삭제된 할 일이 다른 기기에서 다시 나타나지 않도록 삭제 ID와 시각은 동기화 기록에 남을 수 있습니다. 내려받은 JSON 백업은 사용자가 별도로 삭제해야 합니다.

앱에서 연결 해제를 누르면 현재 Google 접근 토큰을 취소하지만 브라우저와 Drive에 저장된 기록은 지워지지 않습니다. Drive의 숨겨진 앱 데이터를 지우려면 먼저 모든 기기에서 Yellow Note 연결을 해제한 뒤, Google Drive의 설정 → 앱 관리에서 해당 앱의 숨겨진 데이터를 삭제하세요. 계속 연결된 기기가 있으면 다음 동기화 때 데이터가 다시 저장될 수 있습니다. 브라우저 기록은 브라우저의 사이트 데이터 관리에서 삭제할 수 있습니다.

4. 보안과 변경

Google 접근 토큰은 현재 앱 실행 중 메모리에만 보관하며 영구 저장하지 않습니다. 웹 연결에는 HTTPS를 사용합니다. 이 방침이 바뀌면 이 페이지의 시행일과 내용을 갱신합니다.
